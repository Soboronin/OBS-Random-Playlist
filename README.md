# ランダム再生リンク ジェネレーター

YouTubeの再生リストから動画をランダムに選んで自動再生する、OBS配信用のブラウザソースです。
本ツールはWebで完結します。

## 使い方

1. [`index.html`](https://soboronin.github.io/OBS-Random-Playlist/)を開く
2. YouTubeの再生リストURLを貼り付けて「リンクを作る」を押す
3. 表示されたURLをコピーする
4. OBSのブラウザソースに、生成されたURLを貼り付ける
※「ローカルファイル」ではなく、通常のURL指定を使用してください
5. OBSのブラウザソースで「OBSで音量を制御する」にチェックを入れる
※動画の音声を流したい場合、チェックが入っていないとOBS画面で音量等が制御できません

## 機能

- 再生リストの動画をランダムな順番で自動再生し続けます
- 既定でミュート再生(切り替え可能)
- 動画の開始直後のタイトル表示、終了間際の関連動画表示をできるだけ避けます
- 埋め込み不可・削除済みの動画は自動でスキップします

## 注意

- （大丈夫だと思いますが）何も指定しないとデフォルトでそぼろ忍の再生リストが流れてしまいますのでご注意ください
- 使用する再生リストは、OBSからアクセスできる状態（公開または限定公開）にしてください
- 本ツールはYouTubeの公式IFrame Player APIのみを使用しており、動画データそのものを保存・再配布するものではありません
- 各動画の視聴・埋め込みはYouTube側の利用規約に従います
- 本ツールは一部生成AIを使用して制作しています
- YouTube側の仕様変更などにより、予告なく正常に動作しなくなる場合があります
